# 我和程序员爸爸 · 视频工作室

## 何时使用

用户提到以下内容时使用本技能：

- 「我和程序员爸爸」「bewithjasper」「亲子闯关」系列
- 要策划新一期视频、写脚本、写口播、写发布文案
- 要给拍摄建议、分镜、封面文案
- 要做单期数据复盘
- 要把一个技术实践（网页工具、App、小程序、SKILL）变成视频选题

## 项目设定

| 角色 | 设定 |
| --- | --- |
| 我 | Jasper，五年级小学生，第一人称口述 |
| 我爸 | 30 多岁程序员，负责写代码、嘴硬、翻车 |
| AI | 家里的第三位成员，负责出题、画图、背锅 |

- **平台**：视频号、抖音、小红书、B 站、公众号
- **调性**：幽默、短、真实、不说教
- **三条主线**：亲子闯关（A）、AI 创作工坊（B）、运动日常（D）；AI 技能课（C）是 A 的知识切片

## 写作规则

1. 第一人称口述，像跟同学聊天，不用书面语
2. 前 3 秒必须有钩子：反差、提问、翻车、身份，至少一个
3. 一条视频只讲一个知识点
4. 爸爸可以自嘲，孩子可以吐槽，但不能不尊重
5. 结尾必须有一个具体、好回答的互动问题
6. 句子短，少用形容词，多用动作和对话
7. 不夸大 AI 能力；不确定的技术细节标注「以实际为准」
8. 不编造数据、不虚构未发生的翻车；没有真实素材就写成「待拍清单」

## 输出格式

### 1. 选题卡

```
### 编号 标题
| 项目 | 内容 |
| 一句话卖点 | |
| 核心看点 | |
| 必拍画面 | ① ② ③ ④ |
| 结尾钩子 | |
```

编号规则：A 亲子闯关、B AI 创作、C 技能课、D 运动日常。

### 2. 分镜脚本

按 `01_脚本/模板-分镜脚本.md` 输出，必须包含：

- 基础信息（时长、平台、卖点、唯一知识点）
- 3 个标题备选
- 3 个开头钩子
- 分镜表（镜号、时间、画面/机位、口播/字幕、音效、备注）
- 结尾互动问题
- 必拍素材清单
- 隐私检查

### 3. 口播稿

按 15 秒左右分段；每段只重读一个词；总时长控制在 60–90 秒（知识课可 3–5 分钟）。

### 4. 发布文案

按 `02_文案/模板-发布文案.md` 输出：

- 标题（5 种类型各 1 个）
- 简介短/中/长三版
- 3–5 个标签
- 封面主副标题
- 评论区置顶

### 5. 复盘

按 `05_复盘/复盘模板.md`，只写数据、三个问题、保留/删除/下次改、一句话结论。

## 工作流

1. 读 `00_选题库/选题总表.md`，确认编号和状态
2. 读对应系列文档（`系列A/B/C/D-*.md`）
3. 生成或更新脚本，存到 `01_脚本/编号-标题.md`
4. 生成发布文案，存到 `02_文案/编号-标题-文案.md`
5. 拍摄、发布、复盘分别引用 `03_拍摄指南/`、`04_发布运营/`、`05_复盘/`
6. 更新选题总表的状态和备注

## 质量检查

发布前逐条确认：

- [ ] 前 3 秒有人物、有冲突、有画面
- [ ] 只有一个知识点
- [ ] 至少一个真实笑点或翻车
- [ ] 结尾问题具体、好回答
- [ ] 标题 ≤ 25 字，含反差/数字/身份之一
- [ ] 没有书面语和说教
- [ ] 隐私与技术敏感信息已处理
