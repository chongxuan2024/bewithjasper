# 我和程序员爸爸 · 视频工作室

## 何时使用

用户提到以下内容时使用本技能：

- 「我和程序员爸爸」「bewithjasper」「亲子闯关」系列
- 要策划新一期视频、写脚本、写口播、写发布文案
- 要给拍摄建议、分镜、封面文案
- 要做单期数据复盘
- 要把一个技术实践（网页工具、App、小程序、SKILL）变成视频选题

## 项目设定

| 角色 | 设定 |
| --- | --- |
| 我 | Jasper，五年级小学生，第一人称口述 |
| 我爸 | 30 多岁程序员，负责写代码、嘴硬、翻车 |
| AI | 家里的第三位成员，负责出题、画图、背锅 |

- **平台**：视频号、抖音、小红书、B 站、公众号
- **调性**：幽默、短、真实、不说教
- **三条主线**：亲子闯关（A）、AI 创作工坊（B）、运动日常（D）；AI 技能课（C）是 A 的知识切片

## 写作规则

1. 第一人称口述，像跟同学聊天，不用书面语
2. 前 3 秒必须有钩子：反差、提问、翻车、身份，至少一个
3. 一条视频只讲一个知识点
4. 爸爸可以自嘲，孩子可以吐槽，但不能不尊重
5. 结尾必须有一个具体、好回答的互动问题
6. 句子短，少用形容词，多用动作和对话
7. 不夸大 AI 能力；不确定的技术细节标注「以实际为准」
8. 不编造数据、不虚构未发生的翻车；没有真实素材就写成「待拍清单」

## 成片格式（默认）

项目已有 A 系列 13 集长录屏，默认采用「第一人称旁白 + 片段穿插」：

- 旁白占约 70%，单独录制；原片只取 6–8 段，每段 3–6 秒
- 成片 60–90 秒，知识课最多 2 分钟
- 原声只留 1–2 处真实反应或提示音，其余静音
- 不直接使用整段录屏，不按原片时间顺序铺
- 旁白必须能独立听懂；不念点击步骤，只讲感受、反差、结论
- 横屏录屏做竖版：录屏居中，上下留标题和字幕，背景用模糊放大
- 有原片时输出「旁白重剪脚本」，模板见 `guide.html#script` 的「模板 1」
- 没有原片时才用分镜脚本，模板见 `guide.html#script` 的「模板 2」
- 完整方法见 `guide.html#edit`（旁白剪辑）

## 输出格式

### 1. 选题卡

```
### 编号 标题
| 项目 | 内容 |
| 一句话卖点 | |
| 核心看点 | |
| 必拍画面 | ① ② ③ ④ |
| 结尾钩子 | |
```

编号规则：A 亲子闯关、B AI 创作、C 技能课、D 运动日常。

### 2. 分镜脚本

按 `guide.html#script` 的「模板 2 · 分镜脚本」输出，必须包含：

- 基础信息（时长、平台、卖点、唯一知识点）
- 3 个标题备选
- 3 个开头钩子
- 分镜表（镜号、时间、画面/机位、口播/字幕、音效、备注）
- 结尾互动问题
- 必拍素材清单
- 隐私检查

### 3. 口播稿

按 15 秒左右分段；每段只重读一个词；总时长控制在 60–90 秒（知识课可 3–5 分钟）。

### 4. 发布文案

按 `guide.html#publish` 和 `#titles` 输出：

- 标题（5 种类型各 1 个）
- 简介短/中/长三版
- 3–5 个标签
- 封面主副标题
- 评论区置顶

### 5. 复盘

按 `guide.html#retro`，只写数据、三个问题、保留/删除/下次改、一句话结论。

## 工作流

1. 打开 `index.html`（或读对应 `*/data.js`），先看该系列的文案、拍摄建议和五步清单
2. 需要路线图、模板、拍摄/剪辑/发布/复盘方法时，读 `guide.html`：
   - 制作与发布顺序：`#roadmap`
   - 脚本模板：`#script`
   - 拍摄清单：`#shoot`
   - 旁白剪辑：`#edit`
   - 发布与复盘：`#publish`、`#retro`
   - 标题与金句：`#titles`
3. 有原片 → 用「旁白重剪」模板；没原片 → 用「分镜脚本」模板；知识课 → 用「口播逐字稿」模板
4. 脚本和文案直接在对话里输出，文案必须是**小学生第一人称**；不再新建 Markdown 文件
5. 新选题写进对应 `*/data.js`（标题、文案、拍摄建议、默认清单），刷新页面即可看到
6. 进度以系列库的五步清单为准：选题确认 → 素材就绪 → 旁白录音 → 剪辑完成 → 已发布
7. 复盘结论写进该集备注，必要时把新选题补进 `data.js`

## 质量检查

发布前逐条确认：

- [ ] 前 3 秒有人物、有冲突、有画面
- [ ] 只有一个知识点
- [ ] 至少一个真实笑点或翻车
- [ ] 结尾问题具体、好回答
- [ ] 标题 ≤ 25 字，含反差/数字/身份之一
- [ ] 没有书面语和说教
- [ ] 隐私与技术敏感信息已处理
