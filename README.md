# 我和程序员爸爸 · 内容工作室

> 一个五年级小学生 + 一个 30 多岁的老程序员，用 AI 一起做游戏、学知识、拍视频，顺便翻车。

## 这是什么

这是「bewithjasper」的内容生产仓库。所有选题、脚本、拍摄计划、发布文案和复盘都放在这里，方便一期一期往下做。

三条内容主线：

| 主线 | 关键词 | 想要的效果 |
| --- | --- | --- |
| 亲子闯关 | 学习游戏化、AI 出题、错题分析 | 让学习像打游戏，孩子主动想通关 |
| AI 创作工坊 | 网页工具、上架 App、小程序、SKILL、数字人 | 把创意真的做出来，顺便讲清楚原理 |
| 运动日常 | 引体向上、跳绳、跑步 | 真实、好笑、有反差，拉近距离 |

统一人设：

- **我**：Jasper，五年级，第一人称口述
- **我爸**：30 多岁程序员，负责写代码、嘴硬、翻车
- **AI**：家里的第三位成员，负责出题、画图、背锅

统一风格：**第一人称、幽默、简短、不说教**。

## 一期视频的生产流程

1. **选题**：在 `00_选题库/选题总表.md` 里挑一个，状态改成「策划中」
2. **脚本**：复制 `01_脚本/模板-分镜脚本.md`，按 `系列X-编号-标题.md` 命名
3. **拍摄**：对照 `03_拍摄指南/拍摄清单.md`，先拍反应再补过程
4. **剪辑**：粗剪 → 字幕 → 音效 → 封面 → 导出竖版和横版
5. **文案**：用 `02_文案/模板-发布文案.md` 生成标题、简介、标签
6. **发布**：对照 `04_发布运营/发布清单.md`，多平台错开时间
7. **复盘**：24 小时后填 `05_复盘/复盘模板.md`，把结论写回选题总表

## 状态标记

`灵感` → `策划中` → `脚本完成` → `已拍摄` → `已剪辑` → `已发布` → `已复盘`

不想做了就标 `搁置`，别删，半年后可能又香了。

## 先从哪期开始

| 顺序 | 期数 | 理由 |
| --- | --- | --- |
| 第 1 期 | D01 引体向上 | 10 分钟能拍完，先练手，建立「反差萌」人设 |
| 第 2 期 | A01 闯关小游戏介绍 | 正式开启亲子闯关系列，有成品可展示 |
| 第 3 期 | A09 什么是 SKILL | 知识线立住，为后面「AI 出题」做铺垫 |
| 第 4 期 | A10 用 SKILL 读课本出题 | 把学习和 AI 真正连起来 |
| 第 5 期 | B03 做一个网页小工具 | 展示「创意能变成真东西」 |

之后保持每周 1–2 期，A 系列和 D 系列交替，B/C 系列穿插。

## 三条底线

1. **孩子不想拍就停**，不演、不逼、不拿哭脸当素材
2. **隐私打码**：门牌、学校、车牌、快递单、代码密钥一律不出现
3. **不吹牛**：AI 能做到什么就说什么，技术细节标注「以实际为准」
