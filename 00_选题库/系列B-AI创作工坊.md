# 系列 B · AI 创作工坊

> **核心设定**：把脑子里的点子真的做出来——网页工具、小游戏、App、小程序、游戏角色、数字人。重点不是「炫技」，而是记录一个五年级孩子和一个程序员爸爸，从想法到成品的全过程，包括翻车。
>
> **更新节奏**：每两周 1 期，可与 A 系列交替。

## B1 · 内容与工具

### B01 发布一篇公众号

| 项目 | 内容 |
| --- | --- |
| 一句话卖点 | 把一次父子实践写成 1500 字：家长看方法，孩子看热闹。 |
| 文章结构 | 痛点 → 我们怎么试 → 3 个可复制步骤 → 翻车点 → 下期预告 |
| 必拍画面 | 选题会、写稿、排版、按下「群发」那一刻 |
| 提醒 | 标题 ≤ 25 字，摘要 ≤ 54 字；文末放下期视频预告 |

## 选题判断标准

拍之前问三个问题：

1. **有成品吗？** 能看见、能玩、能打开，比纯讲概念好看 10 倍
2. **有翻车吗？** 一次成功的故事没人看，修 bug 的过程才有人看
3. **孩子能讲明白吗？** 如果孩子讲不出来，说明这期变成爸爸的个人秀了
