# 系列 C · AI 技能课

> **核心设定**：把 A 系列里「用 AI 出题」的部分单独拆出来，做成 60 秒–5 分钟的知识课。A 系列负责「记录故事」，C 系列负责「讲清原理」。
>
> **适合人群**：想在家用 AI 辅导孩子的家长；对 AI 好奇的小学生。
>
> **更新节奏**：A 系列播到 A09 之后开始更新，每期一个概念。

## C01 3 分钟讲清楚什么是 SKILL

| 项目 | 内容 |
| --- | --- |
| 一句话卖点 | SKILL 就是给 AI 的一份「工作说明书」，写一次，以后都能用。 |
| 核心比喻 | 不是每次都口头交代，而是给 AI 一本「岗位手册」 |
| 结构 | ① 没有 SKILL：每次都要重复说 ② 有 SKILL：一句话触发 ③ SKILL 里到底写了什么 ④ 什么时候该做 SKILL |
| 必拍画面 | 白板画流程、对比实验、打开 SKILL.md 特写 |
| 结尾钩子 | 下期现场做一个「出题 SKILL」。 |

## C02 现场做一个「出题 SKILL」

| 项目 | 内容 |
| --- | --- |
| 一句话卖点 | 把我爸脑子里的「怎么出题」掏出来，写成 AI 能看懂的文件。 |
| 核心看点 | 从需求 → 规则 → SKILL.md → 测试 |
| 结构 | ① 先问：好题目长什么样 ② 列 5 条规则 ③ 写成 SKILL.md ④ 用课本单元测试 ⑤ 发现漏洞再改 |
| 必拍画面 | 规则清单、文件结构、第一次运行失败、修改后成功 |
| 结尾钩子 | 这个 SKILL 出的题，我自己先做一遍。 |

## C03 用 SKILL 出题 → 做题 → 错题报告（连载）

| 项目 | 内容 |
| --- | --- |
| 一句话卖点 | AI 出题、我做题、AI 分析我——一套流程跑三周。 |
| 连载规划 | 第 1 期：出题 + 做题；第 2 期：错题归因；第 3 期：专项加练；第 4 期：复测对比 |
| 核心看点 | 真实分数变化；薄弱点是否真的被补上 |
| 必拍画面 | 出题、做题、批改、报告、复测 |
| 提醒 | 不要只拍「分数提高」，没提高也是好内容 |
