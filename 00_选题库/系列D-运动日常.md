# 系列 D · 运动日常

> **核心设定**：不讲课、不做工具，就拍父子运动的真实反差。爸爸是「理论王者、实战青铜」，孩子是「嘴强王者、偶尔真强」。
>
> **时长**：30–45 秒为主，适合日更/周更。
>
> **风格**：第一人称口述 + 字幕吐槽 + 反差 BGM。

## D01 引体向上：最短行程辅助引体

**成片文案（可直接用）**

> 这是我爸，一名 30 多岁的老程序员。
> 今天他带我来锻炼。一上来，他非要先给我演示一下引体向上。
> 他这……好像也不太行了？和网上平均水平还有很大差距。
> 看我的——
> 最短行程辅助引体。

| 项目 | 内容 |
| --- | --- |
| 一句话卖点 | 爸爸演示 0.5 个，孩子展示「最短行程」1 个。 |
| 必拍画面 | ① 爸爸走向单杠的背影 ② 爸爸拉不上去 ③ 孩子表情 ④ 孩子「最短行程」 ⑤ 爸爸无语 |
| 机位 | 低机位仰拍爸爸（显得强）；平视拍孩子；最后切爸爸表情特写 |
| 剪辑 | 爸爸部分配燃向 BGM，拉不上去瞬间音乐戛然而止；孩子部分换轻快音乐 |
| 字幕梗 | 「最短行程」「辅助」「这就是程序员的核心力量」 |
| 结尾钩子 | 我爸说他只是没热身，你们信吗？ |

## 运动系列拍摄提醒

1. **安全第一**：引体向上用辅助带/矮杠，别逞强；跑步避开车辆
2. **先热身再拍**，别为了镜头拉伤
3. **真实优先**：做不动就做不动，比硬撑好看
4. **爸爸别抢戏**：爸爸的「翻车」是配角，孩子才是主角
5. **固定机位 + 手机足够**，不需要专业设备
