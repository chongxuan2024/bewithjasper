# 拍摄清单

> 每次开拍前 10 分钟过一遍，拍完再对照「必拍素材」检查。

## 一、开拍前 10 分钟

- [ ] 手机电量 > 50%，存储 > 10GB
- [ ] 开勿扰模式，关微信/QQ/系统通知
- [ ] 擦镜头（衣角也行）
- [ ] 麦克风试录 10 秒，回放听有没有杂音
- [ ] 背景收拾：不露门牌、学校名、快递单、证书
- [ ] 孩子先玩 5 分钟，进入状态再开机
- [ ] 脚本只记 3 个关键点，不背全文
- [ ] 约定「再来一次」的暗号，避免打断节奏
- [ ] 录屏软件就位（系统录屏 / OBS）
- [ ] 拍完立即导出，别等手机满

## 二、机位

| 机位 | 用途 | 设备 | 设置 |
| --- | --- | --- | --- |
| A 机 | 父子同框、全景 | 手机 + 三脚架 | 竖屏 9:16，固定不动 |
| B 机 | 表情、手部特写 | 手机手持 | 跟随，别抖 |
| C 机 | 游戏/代码录屏 | 电脑 | 1080p 60fps |

- 主发竖版；B 站/公众号需要横版，拍摄时用横屏多留一份
- 特写比全景值钱：表情、手、屏幕，各拍 3 条

## 三、收音

- 领夹麦最优；没有就让手机离人 50cm 以内
- 录屏时系统声音和麦克风分开录，后期好调
- 关空调、风扇，避开冰箱和洗衣机
- 说话前先录 3 秒环境音，方便降噪

## 四、光线

- 白天面向窗户，不要背光
- 晚上用一盏台灯补脸，别用顶灯直打（会有阴影）
- 屏幕反光就调角度，别让脸黑成剪影

## 五、录屏

- 关通知、关弹窗、隐藏书签栏
- 浏览器/编辑器字体放大到 125%
- 代码里的 token、密钥、内网地址提前打码
- 录前说「3、2、1 开始」，方便对齐音画
- 提前 10 秒开录，翻车往往在准备阶段

## 六、素材命名

```
A01_20261101_A机位_开场.mp4
A01_20261101_B机位_爸爸喝水.mp4
A01_20261101_录屏_第一关.mp4
A01_20261101_成片_竖版_v1.mp4
A01_20261101_封面.png
```

规则：`编号_日期_机位_内容`，日期用 8 位，版本用 v1/v2。

## 七、拍摄中的五条铁律

1. **先拍反应，再补过程**——真实表情只有一次
2. **每条素材多录 3 秒**——留剪辑余量
3. **一次只讲一个知识点**——贪多必剪
4. **翻车比成功好看**——别急着删失败素材
5. **孩子不想拍就停**——不演、不逼、不拿哭脸当素材

## 八、隐私与安全

- [ ] 不拍门牌、学校名、车牌、快递单
- [ ] 不暴露真实姓名、班级、定位
- [ ] 代码中的密钥、token、内网地址已打码
- [ ] 聊天记录去掉头像、昵称、手机号
- [ ] 使用他人肖像（含 AI 数字人）已获授权
- [ ] 发布前给家人过一遍

## 九、收工检查

- [ ] 当天素材已导出并备份（手机 + 电脑）
- [ ] 录屏、花絮、封面素材分文件夹放好
- [ ] 在选题总表把状态改成「已拍摄」
- [ ] 记一句「今天最好笑的瞬间」，写进复盘
